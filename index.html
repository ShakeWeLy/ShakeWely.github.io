2026年8月16日-nnModel详解04-SAM

参考:https://zhuanlan.zhihu.com/p/667801207

0 前置

1.1 主要贡献

  1. prompt输入
  2. 解决歧义的问题: 能够对含糊的指令做出响应，产生多个可能的分割结果
  3. 数据标注策略
  4. 多模态输入

1.2 整体结构

SAM的内部结构。模型由3个主要部分组成：提示词编码器、图像编码器和一个轻量级的掩码解码器。

2 细节

2.1 prompt

1 prompt处理

这里的提示信息可以是mask、points、box或者是text，

如果是mask的话则使用卷积来进行表示，
如果是其余的三种提示词则使用位置编码的形式来进行表示，其中text可以通过clip一类的模型获取词嵌入

2 encoder

首先，mask提示允许我们直接在原像上指示感兴趣区域来引导模型。这些mask通过卷积操作被转换为与图像嵌入空间相匹配的特征，然后与图像嵌入相加结合，为模型提供分割的精确位置信息。如果没有使用mask提示，则用一组可学习向量(no_mask_embed, 1×256) expand为256×64×64后替代。

而文本提示，利用了CLIP的文本编码器，将描述性的语言输入转换为模型可以理解的嵌入向量。比如输入“黑耳朵的猫”，文本编码器就能将这些词转换为一个强大的特征描述，引导模型聚焦于具有这些特征的图像区域。

2.2 图像

1 图像预处理

首先，我们以保持图像的宽高比的方式将图像最长边放缩到1024。

接下来是颜色归一化。通过从每个像素中减去平均值并除以标准差，颜色归一化的目的是为了统一不同图像的颜色范围，减少照明条件和设备差异对模型训练的影响，从而提高模型的泛化能力和加快训练速度。

最后，我们会应用填充（Padding），以确保所有的图像都有相同的维度即1024*1024.

2 image encoder

这部分使用VIT, 主要是SAM理解图像的重要部分

2.1 path embedding

使用一个kernel size且stride为16的卷积核, 将1024的图像提取为64x64x768的深度特征向量;

并加上位置标明

2.2 element-wise add

2.3 transformer

使用了12个Transformer块来处理这些向量，每个块都在维持序列信息的同时，增强了特征的表示。

2.4 降维

2.3 mask decoder

1 decoder

Mask decoder的职责是整合来自图像嵌入的丰富视觉信息和提示词编码器提供的表征信息，其最终目的是解码出精确的语义分割掩码。

mage embedding。它不仅包含了原始图像的信息，还融入了稠密的prompt掩码信息。通过这样的融合，我们得到了一个增强的图像表征，它更全面地捕捉了图像内容和用户指示的分割意图。

tokens不只是承载了稀疏的prompt掩码信息，它们还包括用于未来预测的特殊token——一个预测交并比（IOU）的token和四个预测掩码的token。
mask tokens的角色是作为预测具体分割掩码的占位符，之所以有四个，是因为SAM模型的灵活性允许它在模糊语义下生成多达三个掩码，或者在需要时只生成一个特定掩码。

2 attention

mask decoder的内部机制，以及数据是如何在这一复杂结构中流动和转换的。

首先，tokens被送入mask decoder，并进行自我注意力（self-attention）处理。自我注意力机制的作用是让模型学会在tokens内部寻找和放大重要的关系

经过自我注意力处理的tokens作为查询（query），与图像嵌入的键（key）和值（value）结合进行图像到token的注意力（token to image attention）操作(不再是自注意力机制)
目的是将经过提示词处理的信息与原始图像的丰富上下文信息结合起来，从而为解码过程引入了视觉信息。

结果通过一个多层感知器（MLP）层，产生新的特征表征。

最后, 这些新特征表征随后被用作键K和值V，图像嵌入作为查询Q，执行另一轮图像到token的注意力（image to token attention）操作，进一步精炼模型对图像的理解。

这里有点精妙的, 既把prompt作为Q, 又让image作为Q; 既融合和自注意力, 有又prompt和image的注意力

3 output

在模型的输出阶段，有两个分支。

一分支通过两次转置卷积操作，将维度从256×64×64提升至32×256×256，这样做是为了将特征映射回原始图像的尺寸。

另一分支则使用前面MLP的输出作为查询，执行token到图像的注意力（token to image attention）操作，生成两个输出流：一个是IoU输出token（1×256），它经过一个MLP层后，可以预测每个预测掩码与真实掩码间的交并比（IoU）；另一个输出是每个掩码的输出token（4×256），经过四个MLP层后得到(1+3)×32的张量。

2.4 output

1 mask postprocess

2 anything

预先在图像上均匀分布32×32个点; 点是并行处理, 每个点的处理都是独立的, 每个点都独立地引导SAM去理解和解析图像的不同部分. 最后，去重保留剩下的mask，作为模型的最终输出。

3 训练与推理

3.1 模型参数

不同参数主要在image encoder上, 其次是mask decoder，而prompt encoder参数量最少。

3.2 训练数据

SA-1B数据集的制作过程可以分为三个主要阶段。首先是辅助人工阶段，在这个阶段，使用公开的数据集训练了一个SAM模型。然后，标注员基于SAM预测的掩码进行修改，这个过程经过了5次的迭代，以确保数据的准确性。接下来是半自动阶段，主要用于标注传统语义分割不太关注的物体。同样，这个阶段也经过了5次的迭代，以提高数据的质量。最后是全自动阶段，采用了一系列技巧，如数据增强、更大的掩码解码器、更长时间的训练等，以进一步提升SAM生成的掩码的质量。

3.3 模型训练

采用了“通过在每个掩码上随机采样提示词进行11轮模拟交互设置”的方法来自动化构造提示词。

随后，每一种构造的提示词都会与原图一起被送入解码器。解码器对每种提示进行处理，生成相应的掩码logits。每个掩码logits都会与真实的掩码标签进行比较，计算出一个损失值。

这个损失值是模型学习过程中的关键反馈，它告诉模型预测的掩码与实际标注之间的相似度。通过这样的训练过程，SAM模型逐步学会如何更准确地预测掩码，即使在缺乏确切指示的情况下也能做出正确的分割。这种训练方法不仅提高了模型对用户输入的敏感性，也增强了模型处理不确定性的能力。

3.24 损失函数

1. focal loss

在图中，我们研究单个样本。横坐标表示预测正确的概率（前景预测为前景的概率，背景预测为背景的概率），纵轴表示在不同概率下的损失值。我们首先看到了交叉熵损失（Cross Entropy Loss，CE），它是常用的分类损失函数。然后，我们引入了焦点损失（Focal Loss，FL），其中γ表示一个控制焦点损失下沉程度的超参数。

当γ等于0时，焦点损失等同于交叉熵损失，如图中最上面的蓝色曲线所示。但随着γ的增加，曲线逐渐下沉, 这种下降导致GT值在高位时(>0.6), 此时的 Loss 被剧烈压低（衰减了约 99%），使得大量容易分类的背景样本产生的梯度被大幅抑制, loss下降不会那么明显;
而小于0.6部分loss值受到抑制较小，保留了大部分 Loss, 梯度会更加明显, 而这一部分往往都是难样本所在位置

因此，焦点损失的关键在于它能够聚焦于难以分类的样本，帮助模型更好地应对类别不平衡问题，从而提高了模型的性能。

3.5 多模态

1 clip

实现文本和图片的嵌入到特征空间, 实现对齐. 从而衡量文本和图像的相似性

在训练过程中，我们使用CLIP的图像编码器（CLIP image encoder）来获得图像嵌入（image embeddings）。然后，将这些图像嵌入作为文本的提示词（prompt）

2026年8月15日 语义分割汇总

0 前置

https://zhuanlan.zhihu.com/p/27794982

1 是什么

语义分割是指对图片的像素进行分类. 有别于实例分割, 语义分割不能区分同一类的不同个体

  • 实例分割：实例分割就是对同一类的不同对象也要进行分割，比如说，语义分割会将车分为一类，人分为另一类。但是，实例分割不同的是，它会将车继续进行分类，每一辆车都是一个实例类别。
  • 全景分割：简单地来讲，全景分割是实例分割与语义分割的结合。全景分割中的每一个像素点都会分成对应的语义标签和实例标签。如果一种类别里有多个实例，会用不同的颜色进行区分，我们可以知道哪个像素属于哪个类中的哪个实例。

2 为什么

3 有哪些方法

传统的的语义分割采用CNN的全连接, 所以采用图像块分类; 但后来基本采用了不带全连接的 完全卷积网络. 使得分割图谱可以生成任意大小的图像，且与图像块分类方法相比，也提高了处理速度。

除此之外, 在分割问题中很难使用CNN网络的另一个问题是存在池化层。 因为池化层会聚合背景, 丢弃位置信息, 增大下一次卷积的感受野. 然而，语义分割方法需对类别图谱进行精确调整，因此需保留池化层中所舍弃的位置信息。

池化层放大感受野的代价：通过把特征图缩小（例如 256×256→128×128256 \times 256 \rightarrow 128 \times 128256×256→128×128）来让后面的 3x3 卷积看清更大的范围，代价是丢失了 75% 的空间细节，导致边界模糊。

所以产生了两种不同的方法

3.1 encoder-decoder结构

编码器使用池化层逐渐缩减输入数据的空间维度，而解码器通过反卷积层等网络层逐步恢复目标的细节和相应的空间维度。从编码器到解码器之间，通常存在直接的信息连接，来帮助解码器更好地恢复目标细节。在这种方法中，一种典型结构为U-Net网络。

3.2 空洞卷积结构

不采用池化操作

3.3 条件随机场(Conditional Random Field，CRF)

**通常在后期处理中用于改进分割效果。**CRF方法是一种基于底层图像像素强度进行“平滑”分割的图模型，在运行时会将像素强度相似的点标记为同一类别。加入条件随机场方法可以提高1~2%的最终评分值。

2026年8月15日 nnModel详解02-FCN

0 前置

https://blog.csdn.net/wzk4869/article/details/129702031

https://zhuanlan.zhihu.com/p/27794982

1 是什么

FCN主要实现采用CNN的方法, 实现对图像进行像素级的分类.

经典的CNN图像分类是在卷积层后添加全连接网络+Softmax输出固定长度的特征向量, 进行分类
而FCN并没有采用全连接的方式, 而是使用对最后一层卷积的特征向量进行反卷积操作, 生成与输入图像相同尺寸(任意)的图像, 从而对每一个像素进行预测.

这种操作, 既保留的全局的空间信息, 又对每一个像素进行了分类

2 为什么

语义分割的主要矛盾: 既需要全局信息的搞基语义信息进行语义分类, 有需要低级的是视觉信息进行准确分割

3 怎么做

  1. 用全卷积替代了全连接
  2. 为了弥补下采样操作造成的损失，使用了反转卷积的操作来恢复信息
  3. 用下采样之前的特征图与上采样之后的图片进行融合这样可以指引上采样过程恢复到比较好的效果。即高低通道特征融合。恢复低级视觉信息。

1 网络结构

1.1卷积部分

FCN输入的图像是H*W大小，第一层pooling后变为原图大小的1/4，第二层变为原图大小的1/8，第五层变为原图大小的1/16，第八层变为原图大小的1/32（勘误：其实真正代码当中第一层是1/2，以此类推）。

经过多次卷积和pooling以后，得到的图像越来越小，分辨率越来越低。其中图像到 H/32∗W/32 的时候图片是最小的一层时，所产生图叫做heatmap热图 , 也就是我们需要的高维特征图

1.2 反卷积部分

得到高维特征的heatmap之后就是最重要的一步也是最后的一步对原图像进行upsampling，把图像进行放大、放大、放大，到原图像的大小。

最后的输出是1000张heatmap经过upsampling变为原图大小的图片，为了对每个像素进行分类预测label成最后已经进行语义分割的图像，

为什么是1000张?

最大数值描述（概率）作为该像素的分类

1.3 反卷积

1.4 skip layer

限于精度问题不能够很好地还原图像当中的特征，因此在这里向前迭代。把conv中的卷积核对上一次upsampling之后的图进行反卷积补充细节（相当于一个差值过程）

1 是什么

Unet是一个U形的深度学习网络, 主要由卷积层, 下采样, 上采样和连接组成

2 为什么

1 为图像分割而生

2 不想传统分类模型得出结论,而是需要与原图一直的mask分割掩码图

3

1 网络结构

整个像一个英文字母“U”。左侧的编码器（收缩路径） 和 右侧的解码器（扩张路径）。

三大核心组件:

  1. 左侧的encoder: 负责特征提取
  2. 右侧的decoder: 利用特征
  3. 中间的跳跃连接:

1.1 encoder

负责特征提取:

主要是由:

  1. 两个3X3的卷积层和激活函数组成
  2. 一个2X2的最大池化层, stride=2, size减半

目的:

  1. 提取特征,
  2. 高级语义信息

实现:

1.2 decoder

将编码器提取的高级但粗糙的特征图恢复到原始图像的尺寸，并在此过程中实现像素级的精确定位。

主要由:

  1. 2x2的上采样, 转置卷积
  2. 3x3的卷积层+激活函数
  3. 跳跃连接进行concat

目的

  1. 恢复分辨率
  2. 类似任务头

实现

1.2.1 转置卷积

普通卷积是通过滑动窗口把大图“变小/提炼”；转置卷积则是通过插值填充（Padding） 和 重叠累加 把小图“放大”。

第一步: 插值和填空

  1. stride: 对像素的相邻元素之间进行填充0. stride-1
  2. padding: 普通卷积是整体边缘填充0; 转置卷积是裁剪去padding个0

第二步: 移动

  1. 用卷积核（Kernel）按 stride=1 进行标准的 2D 卷积运算。

1.3 跳跃连接 (Skip Connections) - U-Net 的精髓

Encoder中、下采样之前的特征图，直接“跳跃”到Decoder中，与对应层级上采样之后的特征图进行拼接。

为什么:

  1. 获取来自高分辨率的encoder的特征和局部细节
  2. 获取来自decoder的高纬度特征和全局细节

1.4 完整代码

2 训练

2.1 数据标签

U-Net 处理的是像素级的预测，因此其数据标签不是简单的分类标签（如 class_id），而是与输入图像空间尺寸（H, W）完全一致的掩码图（Mask/Ground Truth）。

  • 二分类分割（Binary Segmentation）：如背景 vs 前景（肿瘤、车道线、建筑物）。
    • 标签形状：[H, W] 或 [1, H, W]
    • 像素取值：0（背景）和 1（目标）的二值图（非 0 即 255 的单通道图片转化而来）。
  • 多类别语义分割（Multi-Class Segmentation）：如背景、器官A、器官B、器官C（共 N 类）。
    • 标签形状：[H, W]
    • 像素取值：每个像素位置的值为类别的类别索引号，取值范围为 [0, N-1]（例如 0 代表背景，1 代表肝脏，2 代表肾脏）。
  • 多标签/多重重叠分割（Multi-Label Segmentation）：一个像素可以同时属于多个类。
    • 标签形状：[N, H, W]（NNN 为类别数）
    • 像素取值：每个通道是一个独立的二值 Mask（取值为 0 或 1）。

2.2 损失函数

损失函数 适用场景 说明与公式特点
BCEWithLogitsLoss (Binary Cross Entropy) 二分类 / 多标签 将每个像素看作独立的二分类。内置 Sigmoid 激活函数，数值稳定性高。

后来慢慢发现，真正的工作并不会按照你的兴趣安排任务。一个项目从需求到落地，算法只是其中的一环。后端、前端、数据库、部署、网络、硬件、现场调试，很多事情都需要有人去完成。如果每一件不会的事情都选择逃避，那永远只能停留在舒适区。

于是，我开始不再抱怨，而是主动去查资料、阅读文档、请教别人、不断实验和验证。虽然很多工作依旧不是我最喜欢的内容，但至少我不会再因为"不会"而拒绝去做，而是想着"怎么才能把它做好"。

这一年里，我接触了模型训练、后端开发、简单的前端页面、工业相机部署、WebRTC、硬件调试、服务器环境等许多以前从未接触过的内容。现在回头看，它们未必都会成为我未来的主方向，却让我拥有了更完整的工程视角。

除了技术之外，我觉得自己还有一个需要反思的地方。

公司的管理相对宽松，我也曾利用这种宽松，做过一些投机取巧的事情，例如利用考勤规则"摸鱼加班"、偶尔提前离开公司等。虽然没有影响工作的完成，但现在回头看，这更多反映的是当时自己的职业意识还不够成熟。

后来我越来越意识到，职业素养并不仅仅体现在技术能力上，也体现在是否能够对自己的时间、工作和行为负责。制度可以宽松，但不能因此降低对自己的要求。这也是这一年里，我觉得自己仍然需要继续改进的地方。

7. 对下一份工作的期待

说实话，我现在依然没有一个百分之百确定的答案。

这一年里，我接触了很多东西：计算机视觉、后端开发、前端、Agent、大模型、部署、运维……每一样都了解了一些，却又都谈不上精通。有时候我也会怀疑，在 AI 发展这么快的今天，这样广而不精到底是不是一件好事。

不过，至少我已经知道自己不希望成为什么样的人。

在技术方向上，我还是希望以计算机视觉作为自己的核心能力。它是我最早接触、也是最感兴趣的领域。未来希望继续深入学习三维视觉、多模态以及医学影像等方向，同时逐步接触 Embodied AI 所涉及的机器人、感知与决策，以及 AI Infra 相关的工程能力。

我不希望一直做一个什么都会一点的人，而是希望先把一个方向做到足够扎实，再慢慢向周围扩展。广度很重要，但深度才是真正的竞争力。

如果让我重新选择一次，我还是会来这家公司。

接下来，也该去看看更大的世界了。

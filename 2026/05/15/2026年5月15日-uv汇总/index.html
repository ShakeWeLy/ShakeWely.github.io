2026年5月15日 uv汇总

uv init 之后python版本是多少

uv init 本身不会“固定”一个 Python 版本，它会：

  1. 使用你当前环境找到的 Python
  2. 生成 pyproject.toml
  3. 自动写一个 requires-python

例如你当前机器默认是 Python 3.12：

我现在uv build 之后只能安装在固定python版本吗?

不是。uv build 构建出来的包，是否“只能安装在固定 Python 版本”，取决于你项目里声明的 Python 兼容范围，而不是 uv build 本身

uv sync 干什么的

uv sync 的核心作用一句话概括就是：

把你的项目环境“同步”成 pyproject.toml + uv.lock 里定义的状态

它做的不是“随便装点包”，而是严格对齐依赖环境。

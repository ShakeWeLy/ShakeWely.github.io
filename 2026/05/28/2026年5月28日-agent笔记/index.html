2026年5月28日 agent笔记

从零构建 Agent 系统：整体架构设计笔记

0. Agent 到底是什么

0.1 什么是 Agent

在我看来, agent是一个可以根据当前情况选择合适工具进行调用的状态机,并且具有循环触发的能力

0.2 Agent 与 ChatBot 的区别

相比chatbot, agent除了具备多轮对话外, 还具备loop能力, 能够持续多轮进行llm调用, 直至任务完成

0.3 Agent 的核心循环

用户输出触发 ->agent loop -> if state==finish -> break

0.4 Agent 系统的整体架构

LLM 负责推理

Tool 负责行动

Memory 负责记忆

Runtime 负责执行

Scheduler 负责调度

Evaluation 负责评估

0.5 为什么 Agent 越来越像操作系统

  • LLM 类似 CPU，负责推理与决策
  • Context / Memory 类似内存（RAM）
  • Vector DB / Knowledge Base 类似硬盘存储
  • Tool 类似外设与系统调用
  • Runtime 类似进程运行环境
  • Scheduler 类似任务调度器

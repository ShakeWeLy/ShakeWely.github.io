2026年7月26日 nnUNet组会汇报

nnU-Net：Self-configuring Method for Deep Learning-based Biomedical Image Segmentation

0 研究背景和痛点（Why）

背景

近年来，深度学习语义分割已经广泛应用于医学图像分析，例如：

  • 器官分割
  • 肿瘤检测
  • 病灶测量
  • 三维重建

通过语义分割，可以完成：

  • 图像分析（Image Analysis）
  • 定量分析（Quantification）

例如：

现有方法存在的问题

虽然 U-Net、V-Net 等模型已经取得很好效果，但是：

不同数据集几乎都需要重新设计整个训练流程。

主要包括：

  • 数据预处理
  • 网络结构
  • Patch Size
  • Batch Size
  • Learning Rate
  • Data Augmentation
  • 后处理

这些设计高度依赖：

  • 数据集特点
  • GPU显存
  • 医学经验

因此：

一个新的医学分割任务往往需要大量人工调参。

AutoML 为什么不能解决？

AutoML 可以自动搜索网络。

但是：

  • 搜索成本高
  • 计算资源巨大
  • 仍需要人工定义搜索空间

因此，

AutoML 并没有真正消除专家经验。

nnU-Net 的目标

作者希望做到：

输入一个新的医学数据集，不需要任何人工配置，就能够自动训练出高性能分割模型。

1 核心思想（How）

作者认为：

整个分割流程其实包含三种类型的设计决策：

这就是 nnU-Net 最核心的思想。

（1）Fixed Parameters

固定参数。

作者发现：

很多经验其实对于所有数据集都成立。

例如：

  • 使用 U-Net
  • Deep Supervision
  • Instance Normalization
  • LeakyReLU

这些无需重新设计。

因此：

固定下来。

（2）Rule-based Parameters

规则参数。

作者提出两个概念：

Dataset Fingerprint

数据指纹。

包括：

也就是：

数据集有哪些特点。

Pipeline Fingerprint

流水线指纹。

包括：

也就是：

如何训练这个模型。

二者关系

所以：

不再靠人工，而是靠规则自动决定。

（3）Empirical Parameters

还有一些参数，

无法直接写规则。

例如：

  • 哪个模型最好
  • 是否需要Cascade
  • 后处理方式

作者采用：

因此称为：

Empirical Parameters。

nnU-Net 自动完成哪些事情？

整个流程：

包括：

Preprocessing

自动：

  • Resampling
  • Cropping
  • Normalization

Network

自动决定：

  • 2D U-Net
  • 3D Full Resolution
  • 3D Cascade

其中：

Training

自动：

  • Patch Size
  • Batch Size
  • Learning Rate
  • Data Augmentation
  • Deep Supervision

Post-processing

自动：

  • Remove Small Components
  • Keep Largest Component

全部自动完成。

数据集

  • MRI

  • EM
  • FM

包括：

  • Brain

  • Tumor

几乎覆盖所有医学分割场景。

对比方法

与：

  • 各挑战赛冠军
  • 专门设计的方法
  • 人工调参模型

进行比较。

实验结果

最终：

说明：

即使没有针对任务专门设计，nnU-Net 依然能够超过大多数人工设计方法。

为什么效果这么好？

作者强调：

并不是因为：

  • 新网络
  • 新Loss
  • 新Optimizer

而是：

把多年人工调参经验进行了系统化总结。

3 讨论与启发（Discussion）

第一

论文最大的贡献不是：

一个新的网络。

而是：

自动配置整个分割流程。

这也是后来：

Auto Configuration

Auto Pipeline

Medical AutoML

发展的基础。

第二

作者认为：

真正影响性能的，

不是网络结构，

而是：

一句经典结论：

The exact architecture is not the most important determinant in getting a good solution.

即：

网络结构并不是决定模型性能最重要的因素。

第三

nnU-Net 更像一个：

任何新的：

  • Transformer
  • Attention
  • Mamba
  • Diffusion

都可以直接放进去。

因此，

很多后续工作都是：

而不是重新设计整个Pipeline。

第四（局限性）

虽然 nnU-Net 十分强大，但仍存在一些局限：

  • 默认以 Dice 作为优化目标，对于特殊评价指标的任务可能不是最优。
  • 某些特殊数据（如电子显微镜 EM）仍需要人工设计预处理或损失函数。
  • 启发式规则依赖已有经验，对于全新的数据类型可能需要扩展。

作者提出，可以持续将新的经验融入规则库，使 nnU-Net 不断演进。

总结（Take-home Message）

可以用下面四句话概括整篇论文：

  1. 问题： 医学图像分割高度依赖人工经验，不同数据集需要重新设计整个训练流程。
  2. 方法： 将配置决策划分为固定参数（Fixed）、规则参数（Rule-based）和经验参数（Empirical），根据数据指纹自动生成完整训练流水线。
  3. 结果： 在 23 个数据集、53 个分割任务上取得了 33 个 SOTA，其余任务也达到或接近排行榜最佳水平。
  4. 意义： nnU-Net 的核心创新不是提出新的网络（No New Net），而是把医学图像分割中的专家经验系统化、自动化，建立了一套可直接迁移到新数据集的自配置框架。这也是它成为医学图像分割领域事实标准（de facto standard）的重要原因。

2026年1月27日 torch实战3

1. 模型部署与生产化 (TorchScript & LibTorch)

在实际工业界，模型通常不会运行在 Python 环境下（因为 Python 太重且慢）。你需要学会如何把 PyTorch 模型“脱离” Python。

  • TorchScript： 学习使用 torch.jit.trace（追踪）和 torch.jit.script（脚本化）。这会将你的 Python 代码转换成一种中间表示（IR），它可以被 C++ 直接读取。
  • LibTorch： 这是一个纯 C++ 库。进阶目标是：在 C++ 环境中加载导出的 .pt 模型，并完成前向推理。

2. 分布式训练与大规模计算 (Distributed)

当你处理的数据量达到 TB 级别时，单张 GPU 就力不从心了。

  • DDP (Distributed Data Parallel)： 这是 PyTorch 官方推荐的分布式模式。你需要理解它如何利用 C++ 层的 NCCL 库 在多张显卡之间同步梯度。
  • 混合精度训练 (AMP)： 学习 torch.cuda.amp，利用 Tensor Cores 加速计算，同时减少显存占用。
  • 性能调优 (Profiler)： 使用 torch.profiler 寻找代码瓶颈，看看是 CPU 预处理太慢，还是 GPU 计算太满。

3. 底层自定义算子 (C++/CUDA Extensions)

如果你发现 PyTorch 官方提供的函数（如 conv2d）无法满足你的特殊数学需求，或者 Python 实现的速度太慢，你就需要自己写底层代码。

  • 编写 C++ 扩展： 利用 pybind11 将 C++ 函数映射到 Python。
  • CUDA 编程： 学习编写 .cu 文件，直接操作 GPU 核函数（Kernel）。这是最硬核的技能，能让你的自定义运算速度提升几十甚至上百倍。

4. 源码级阅读 (Internal Mechanism)

既然你对 C++ 感兴趣，可以尝试克隆 PyTorch 的 GitHub 仓库，重点阅读以下模块：

  • ATen 库： 这是 PyTorch 的基础张量库，几乎所有的 C++ 运算都在这里。
  • Autograd 引擎： 查看 torch/csrc/autograd，理解它是如何通过动态链表记录梯度路径的。

模型准备与优化

模型导出格式

PyTorch 主要支持以下导出格式：

格式 特点 适用场景
TorchScript PyTorch原生格式，保持动态图特性 PyTorch生态内部使用
ONNX 开放标准，跨框架兼容 多框架协作环境
Torch-TensorRT NVIDIA优化格式 GPU推理加速

导出为TorchScript

# 方法1: 通过追踪(tracing)导出
traced_script = torch.jit.trace(model, example_input)
traced_script.save(“resnet18_traced.pt”)

# 方法2: 通过脚本(scripting)导出
scripted_model = torch.jit.script(model)
scripted_model.save(“resnet18_scripted.pt”)

注意事项：

  1. torch.jit.trace 更适合没有控制流的模型
  2. torch.jit.script 能处理包含条件判断等复杂逻辑的模型
  3. 导出前务必调用 model.eval()

LibTorch (C++ API)

#include <torch/script.h>

int main() {
// 加载模型
torch::jit::script::Module module;
module = torch::jit::load(“resnet18.pt”);

// 准备输入
std::vectortorch::jit::IValue inputs;
inputs.push_back(torch::ones({1, 3, 224, 224}));

// 执行推理
auto output = module.forward(inputs).toTensor();
std::cout << output.slice(*/*dim=*/*1, */*start=*/*0, */*end=*/*5) << ‘\n’;
}

ONNX Runtime

import onnxruntime as ort

# 创建推理会话
sess = ort.InferenceSession(“model.onnx”)

# 准备输入
input_name = sess.get_inputs()[0].name
input_data = np.random.rand(1, 3, 224, 224).astype(np.float32)

# 执行推理
outputs = sess.run(None, {input_name: input_data})

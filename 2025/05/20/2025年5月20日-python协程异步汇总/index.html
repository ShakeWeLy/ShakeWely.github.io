0 前置

🧠 1）进程（Process）

👉 操作系统分配资源的最小单位

特点：

  • 独立内存空间
  • 真·并行（多核 CPU）
  • 开销最大

适合：

  • CPU 密集（AI训练、图像处理）

🧵 2）线程（Thread）

👉 进程里的执行流

特点：

  • 共享内存
  • 由 OS 调度
  • Python 受 GIL 限制（同一时刻只能一个线程执行 Python 代码）

适合：

  • IO并发（文件、网络）

🪶 3）协程（Coroutine）

👉 用户态的“轻量级线程”（重点）

特点：

  • 不是 OS 管的
  • 是 Python 语言层对象
  • 需要“调度器”执行（asyncio）

核心特征：

本质：

协作式调度（cooperative scheduling）

相对于同步的顺序执行

什么是协程

代码层面的轻量级"线程"由程序（而非操作系统）调度。
通过yield / await交出运行主动权

2 asyncio 库汇总

asyncio 是 Python 标准库中的异步编程框架，用于支持基于协程的并发模型。

它的核心作用是：

提供事件循环（event loop），并调度协程、任务和异步IO操作

1. asyncio 的核心组成

asyncio 主要由以下几个核心部分构成：

（1）事件循环（Event Loop）

事件循环是 asyncio 的核心调度器，用于：

  • 执行协程
  • 管理任务（Task）
  • 处理 IO 事件
  • 控制任务切换

说明：

  • asyncio.run() 会自动创建并启动事件循环
  • 负责整个异步程序的生命周期

（2）协程（Coroutine）

特点：

  • 使用 async def 定义
  • 使用 await 挂起执行
  • 需要事件循环调度执行

（3）任务（Task）

Task 是对协程的进一步封装，用于：

让协程“并发执行”

特点：

  • Task 是“正在执行的协程”
  • 由事件循环调度
  • 可以并发运行多个 Task

（4）Future（未来结果）

Future 表示一个尚未完成但未来会完成的结果对象

特点：

  • Task 是 Future 的子类
  • 用于表示“结果占位”
  • 通常由底层 IO 或 Task 驱动

3. 常用 API 汇总

（1）启动事件循环

作用：

  • 创建 event loop
  • 执行主协程
  • 自动关闭 loop

（2）创建任务

作用：

  • 将协程包装为 Task
  • 立即加入事件循环执行
  • 实现并发执行

（3）等待协程

作用：

  • 挂起当前协程
  • 等待目标协程完成
  • 单任务顺序执行

（4）⭐创建并发等待多个任务（Task）

作用：

  • 并发执行多个任务
  • 等待全部完成
  • 返回结果列表

（5）睡眠（非阻塞）

特点：

  • 不阻塞线程
  • 让出执行权给 event loop

核心思想：

5. asyncio 的特点

  • 单线程并发
  • 非阻塞 IO
  • 高并发（适合 IO 密集型）
  • 任务切换成本低
  • 不适合 CPU 密集型任务

6. asyncio 的适用场景

适合：

  • 网络请求（HTTP / API）
  • 数据库 IO
  • Web 服务（FastAPI）
  • 爬虫
  • 高并发 IO 处理

不适合：

  • 大量 CPU 计算
  • 图像训练 / 深度学习计算
  • 重度数值计算

7. 一句话总结

asyncio 是 Python 的异步框架，通过事件循环调度协程任务，实现单线程下的高并发 IO 处理。
